# CSS Tooltip UI

A CSS-only navigation tooltip component built with HTML and CSS.

This project displays tooltips above navigation links when users hover over them or navigate to them using the keyboard. No JavaScript is used.

## Features

- Tooltips for navigation items
- Mouse hover interaction
- Keyboard-focus interaction
- Fade and slide-in animation
- Tooltip arrow created with CSS
- Responsive navigation layout
- Accessible tooltip markup using `role="tooltip"`

## Built With

- HTML5
- CSS3

## What I Practiced

- `position: relative`
- `position: absolute`
- CSS pseudo-elements
- `:hover`
- `:focus-visible`
- `:focus-within`
- CSS transitions
- Accessible keyboard navigation
